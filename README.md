# E-Commerce Task

A full-stack E-Commerce web application developed using **React.js, Redux Toolkit, ASP.NET Core Web API, Entity Framework Core, and SQL Server**.

The frontend provides user registration, login, product browsing, search, category filtering, cart management, checkout, orders, profile management, and an admin dashboard.

The backend provides REST APIs for authentication, products, categories, cart, orders, and user profile management.

**JWT Authentication** and **role-based authorization** are used to secure user and admin features.

**Redux Toolkit** is used for frontend state management, while **Axios and Fetch** are used for API communication.

**Axios** is used for the user login ,**Fetch** is used for the admin login.

**React Hook Form and Yup** are used for form handling and validation.

The backend follows a **Repository Pattern and Service Layer Architecture** with Entity Framework Core Code First.
